# 네비게이션 패턴

> 단일부터 다중 레벨까지, 네비게이션 구조 설계 가이드. 특히 복잡한 앱의 다중 네비게이션에 집중.

---

## 네비게이션 레벨 정의

```
Level 0: 앱/제품 전환 (워크스페이스, 팀, 프로젝트)
Level 1: GNB — 주요 섹션 (대시보드, 프로젝트, 설정)
Level 2: LNB — 섹션 내 하위 메뉴
Level 3: 페이지 내 탭/앵커
Level 4: 콘텐츠 내 링크/액션
```

---

## 1. 단일 네비게이션 (Level 1만)

간단한 앱, 랜딩 페이지, 단일 기능 도구.

### 패턴 A: Top GNB Only

```
┌─────────────────────────────────────────────────────────┐
│ Logo     [Home] [Features] [Pricing] [Docs]    [Login] │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                     Main Content                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**스펙:**
- 높이: 56-64px
- 로고: 좌측, 32-40px 높이
- 메뉴 항목: 중앙 또는 로고 우측
- 항목 간격: 24-32px
- CTA: 우측 끝

**사용처:** 마케팅 사이트, 문서 사이트, 단순 앱

### 패턴 B: Bottom Tab Bar (Mobile)

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│                     Main Content                        │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  🏠 Home    📊 Stats    ➕    📋 List    👤 Profile    │
└─────────────────────────────────────────────────────────┘
```

**스펙:**
- 높이: 56px + safe-area-inset-bottom
- 항목 수: 3-5개 (5개 초과 금지)
- 아이콘: 24px
- 레이블: 10-11px (생략 가능)
- 활성: primary 색, 아이콘+레이블 동시 강조

**사용처:** iOS/Android 네이티브 앱, 모바일 웹앱

## 2. 2단 네비게이션 (GNB + LNB)

SaaS 대시보드, 관리자 패널의 표준 구조.

### 패턴 A: Top GNB + Left LNB

```
┌─────────────────────────────────────────────────────────┐
│ Logo         [Search]            [🔔] [Avatar ▼]       │  ← GNB
├─────────┬───────────────────────────────────────────────┤
│ Section │                                               │
│ ────────│ Page Title                        [Actions]  │
│ ● Item1 │                                               │
│   Item2 │ Content                                       │
│   Item3 │                                               │
│ ────────│                                               │
│ Section │                                               │
│   Item4 │                                               │
│   Item5 │                                               │
│         │                                               │
│ ────────│                                               │
│ [설정]  │                                               │  ← 하단 고정
├─────────┴───────────────────────────────────────────────┤
```

**GNB 스펙:**
- 높이: 56-64px
- 로고: 좌측, LNB 너비와 정렬
- 검색: 중앙 또는 로고 우측
- 유저 메뉴: 우측 끝, Avatar + 드롭다운

**LNB 스펙:**
- 너비: 240px (펼침), 64px (접힘)
- 패딩: 12-16px
- 섹션 레이블: 12px, uppercase, muted, 8px 상단 여백
- 항목 높이: 40px
- 항목 패딩: 12px 좌우
- 아이콘: 20px, 레이블 좌측 12px 간격
- 활성 항목: primary 배경(10%), primary 아이콘/텍스트
- 호버: surface-hover 배경
- 하단 고정: 설정, 도움말, 로그아웃

### 패턴 B: Left LNB에 로고 포함

```
┌─────────┬───────────────────────────────────────────────┐
│ [Logo]  │ Page Title                        [Actions]  │
├─────────┤                                               │
│ Section │                                               │
│ ● Item1 │ Content                                       │
│   Item2 │                                               │
│ ...     │                                               │
├─────────┴───────────────────────────────────────────────┤
```

**스펙:**
- LNB 상단에 로고 배치 (64px 높이 영역)
- GNB는 페이지 헤더로 대체 (타이틀 + 액션)
- LNB가 브랜드 아이덴티티 담당

**사용처:** 단일 제품 앱, 로고 강조 필요 시

### 모바일 전환

```
Desktop → Mobile 전환:

방법 1: LNB → 햄버거 드로어

│ [🏠] [📊] [📁] [⚙️] [More]            │
```

## 3. 3단 네비게이션 (GNB + LNB + Tab/Subnav)

복잡한 SaaS, 엔터프라이즈 앱.

### 패턴 A: GNB + LNB + Page Tabs

```
┌─────────────────────────────────────────────────────────┐
│ Logo         [Search]            [🔔] [Avatar ▼]       │  ← GNB
├─────────┬───────────────────────────────────────────────┤
│ Section │ Project Name                      [Actions]  │
│ ────────│ ┌───────────────────────────────────────────┐│
│ ● Proj A│ │ [Overview] [Tasks] [Files] [Settings]    ││  ← Page Tabs
│   Proj B│ ├───────────────────────────────────────────┤│
│   Proj C│ │                                           ││
│         │ │           Tab Content                     ││
│         │ │                                           ││
│         │ └───────────────────────────────────────────┘│
├─────────┴───────────────────────────────────────────────┤
```

**Page Tabs 스펙:**
- 높이: 44-48px
- 위치: 페이지 헤더 바로 아래
- 활성 탭: 하단 2-3px 밑줄 (primary), 텍스트 굵게
- 탭 간격: 0px (밀착) 또는 4-8px
- 최대 탭 수: 7개, 초과 시 "더보기" 드롭다운

**사용처:** 프로젝트 상세, 사용자 프로필, 설정 페이지

### 패턴 B: GNB + LNB + Nested LNB

```
┌─────────────────────────────────────────────────────────┐
│ Logo                                   [🔔] [Avatar]   │  ← GNB
├─────────┬───────────┬───────────────────────────────────┤
│ Section │ Subsection│                                   │
│ ────────│ ──────────│ Page Title              [Actions]│
│ ● Inbox │ ● All     │                                   │
│   Sent  │   Unread  │ Content                          │
│   Draft │   Starred │                                   │
│ ────────│           │                                   │
│ Settings│           │                                   │
├─────────┴───────────┴───────────────────────────────────┤
```

**Nested LNB 스펙:**
- Primary LNB: 200px, 주요 섹션
- Secondary LNB: 180px, 선택된 섹션의 하위 메뉴
- 구분: 1px border 또는 배경색 차이
- Primary 선택 → Secondary 내용 변경

**사용처:** 이메일 클라이언트, 파일 관리자, 복잡한 설정

### 패턴 C: GNB + Contextual Subnav

```
┌─────────────────────────────────────────────────────────┐
│ Logo    [Dashboard] [Projects] [Reports]  [🔔] [Avatar]│  ← GNB (주요 섹션)
├─────────────────────────────────────────────────────────┤
│ [All] [Active] [Archived] [Shared]    [+ New Project]  │  ← Subnav (필터/뷰)
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    Content                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**Subnav 스펙:**
- 높이: 48px
- GNB 바로 아래 고정
- 좌측: 필터/뷰 전환 (pill 탭 또는 링크)
- 우측: 페이지 액션 버튼
- 배경: surface 또는 GNB보다 밝게

**사용처:** 리스트 필터링, 뷰 전환이 잦은 페이지

## 4. 다중 컨텍스트 네비게이션

워크스페이스, 팀, 조직 등 최상위 컨텍스트가 있는 경우.

### 패턴 A: Workspace Switcher in GNB

```
┌─────────────────────────────────────────────────────────┐
│ [Workspace ▼] Logo   [Search]          [🔔] [Avatar]   │
├─────────┬───────────────────────────────────────────────┤
│ LNB     │                                               │
│         │ Content                                       │
│         │                                               │
├─────────┴───────────────────────────────────────────────┤

[Workspace ▼] 클릭 시:
┌─────────────────┐
│ ● Team Alpha    │
│   Team Beta     │
│   Personal      │
│ ───────────────│
│ + New Workspace │
└─────────────────┘
```

**스펙:**
- 스위처 위치: 로고 좌측 또는 LNB 최상단
- 현재 워크스페이스: 아이콘/로고 + 이름 + ▼
- 드롭다운: 워크스페이스 목록 + 생성 버튼
- 전환 시: 전체 LNB 내용 변경

### 패턴 B: Sidebar Workspace List

```
┌───┬─────────┬───────────────────────────────────────────┐
│ W │ LNB     │ Content                                   │
│ S │ Section │                                           │
│   │ ● Item1 │                                           │
│ ● │   Item2 │                                           │
│ ○ │         │                                           │
│ ○ │         │                                           │
│   │         │                                           │
│ + │ [설정]  │                                           │
└───┴─────────┴───────────────────────────────────────────┘

WS = Workspace Sidebar (48-56px)
```

**Workspace Sidebar 스펙:**
- 너비: 48-64px
- 아이콘: 32-40px (로고 또는 이니셜)
- 활성: 배경색 + 좌측 3px accent bar
- 호버: 툴팁으로 워크스페이스 이름
- 하단: + 버튼 (새 워크스페이스)

**사용처:** Slack, Discord, Figma 스타일

## 5. 모바일 다중 네비게이션

### 패턴 A: 탭바 + 페이지 내 탭

```
┌─────────────────────────────────────────┐
│ Page Title                    [Action] │
├─────────────────────────────────────────┤
│ [Tab1] [Tab2] [Tab3]                   │  ← 페이지 내 탭
├─────────────────────────────────────────┤
│                                         │
│              Tab Content                │
│                                         │
├─────────────────────────────────────────┤
│  🏠     📊     ➕     📋     👤       │  ← 하단 탭바
└─────────────────────────────────────────┘
```

**규칙:**
- 하단 탭바: 앱의 주요 섹션 (L1)
- 페이지 내 탭: 해당 섹션의 하위 뷰 (L2)
- 스크롤 시: 페이지 내 탭은 sticky 유지 가능

### 패턴 B: 드로어 + 탭바

```
[☰] 탭 → 드로어 열림:
┌─────────────────┬───────────────────────┐
│ Workspace Alpha │                       │
│ ───────────────│                       │
│ Dashboard       │      Dimmed           │
│ Projects        │      Background       │
│ Settings        │                       │
│                 │                       │
│ ───────────────│                       │
│ Switch Workspace│                       │
│ Log Out         │                       │
└─────────────────┴───────────────────────┘
```

**드로어 스펙:**
- 너비: 280-320px (또는 화면의 80%)
- 상단: 현재 워크스페이스/유저 정보
- 중앙: 네비게이션 항목
- 하단: 설정, 로그아웃 등
- 배경 딤: rgba(0,0,0,0.5), 탭 시 닫힘

### 패턴 C: Push Navigation

```
Screen 1 (List)    →    Screen 2 (Detail)   →    Screen 3 (Edit)
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ Projects        │    │ ← Project A     │    │ ← Edit Project  │
├─────────────────┤    ├─────────────────┤    ├─────────────────┤
│ Project A    >  │ →  │                 │ →  │ Name: [      ]  │
│ Project B    >  │    │ Details...      │    │ ...             │
│ Project C    >  │    │                 │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

**스펙:**
- 뒤로 가기: 좌상단 "←" 또는 iOS 스와이프 백
- 전환 애니메이션: 우→좌 슬라이드 (push), 좌→우 (pop)
- 깊이: 3-4단계 이상이면 구조 재검토 필요

## 네비게이션 설계 원칙

### 1. 깊이 vs 너비

```
깊이 줄이기: 클릭 수 최소화
너비 줄이기: 선택지 수 최소화

권장: 
  L1 (GNB): 5-7개 항목
  L2 (LNB): 10-15개 항목 (그룹화)
  L3 (Tab): 3-7개 탭
```

### 2. 현재 위치 표시

```
모든 레벨에서 "지금 어디인지" 명확히:
  GNB: 활성 항목 하이라이트
  LNB: 활성 항목 배경색 + 아이콘 색상
  Breadcrumb: 3단계 이상일 때 추가
  Page Title: 항상 표시
```

### 3. 일관된 패턴

```
같은 앱 내에서:
  모든 페이지가 동일한 네비게이션 구조 유지
  LNB 위치, 너비, 스타일 통일
  모바일 전환 패턴 통일
```

### 4. 접근성

```
키보드 네비게이션:
  Tab: 다음 항목으로 이동
  Enter/Space: 항목 활성화
  Arrow: 메뉴 내 이동
  Esc: 드롭다운/드로어 닫기

Skip Link:
  "메인 콘텐츠로 건너뛰기" — 키보드 사용자용
```

## 반응형 브레이크포인트 가이드

```
Desktop (1280px+):
  GNB + LNB 펼침 + 풀 콘텐츠
  탭은 가로 배치

Tablet (768-1279px):
  GNB + LNB 접힘(64px) 또는 드로어
  탭 유지 (스크롤 가능)

Mobile (<768px):
  햄버거 + 드로어 또는 하단 탭바
  페이지 내 탭은 가로 스크롤 또는 세그먼트 컨트롤
  Master-Detail은 Push Navigation으로 전환
```
