# 페이지 레이아웃 패턴

> 자주 쓰이는 페이지 구조와 레이아웃. 목적에 맞는 패턴을 선택하라.

---

## 레이아웃 선택 기준

| 목적 | 권장 레이아웃 |
|-----|-------------|
| 데이터 개요 + 모니터링 | Dashboard Layout |
| 목록에서 상세 탐색 | Master-Detail Layout |
| 설정/프로필 편집 | Settings Layout |
| 긴 폼 입력 | Form Page Layout |
| 문서/블로그 읽기 | Content Layout |
| 마케팅/전환 | Landing Page Layout |

---

## 1. Dashboard Layout

KPI, 차트, 테이블을 한눈에 보여주는 데이터 중심 레이아웃.

### 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB (또는 App Bar)                                       │
├─────────┬───────────────────────────────────────────────┤
│         │ Page Header (타이틀 + 기간 필터 + 액션)          │
│   LNB   ├───────────────────────────────────────────────┤
│         │ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐│
│  240px  │ │ Stat 1  │ │ Stat 2  │ │ Stat 3  │ │ Stat 4  ││  ← KPI 카드 행
│         │ └─────────┘ └─────────┘ └─────────┘ └─────────┘│
│  접힘:  │ ┌─────────────────────┐ ┌───────────────────┐ │
│  64px   │ │                     │ │                   │ │
│         │ │   Main Chart        │ │   Secondary       │ │  ← 차트 영역
│         │ │                     │ │                   │ │
│         │ └─────────────────────┘ └───────────────────┘ │
│         │ ┌─────────────────────────────────────────────┤
│         │ │ Data Table                                  │  ← 상세 데이터
│         │ │                                             │
│         │ └─────────────────────────────────────────────┤
├─────────┴───────────────────────────────────────────────┤
```

### 스펙

```
LNB 너비: 240px (펼침), 64px (접힘)
메인 영역 패딩: 24px (desktop), 16px (mobile)
KPI 카드 그리드: 4열 (desktop) → 2열 (tablet) → 1열 (mobile)
KPI 카드 높이: 100-120px
차트 영역: 2:1 또는 3:2 비율 분할
차트 높이: 300-400px
테이블: 나머지 공간, min-height 300px
섹션 간 gap: 24px
```

### 반응형 전환

```
Desktop (1280px+): LNB 펼침 + 4열 KPI + 차트 2열
Tablet (768-1279px): LNB 접힘 + 2열 KPI + 차트 1열
Mobile (<768px): LNB 드로어 + 1열 KPI + 스택 레이아웃
```

## 2. Master-Detail Layout

목록에서 항목을 선택하면 옆에 상세가 나타나는 패턴. 이메일, 메시지, 파일 관리 등.

### 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB                                                      │
├─────────┬─────────────────┬─────────────────────────────┤
│         │ List            │ Detail                       │
│   LNB   │ ┌─────────────┐ │ ┌─────────────────────────┐ │
│         │ │ Item 1 ●    │ │ │ Title                   │ │
│         │ ├─────────────┤ │ │                         │ │
│         │ │ Item 2      │ │ │ Content                 │ │
│         │ ├─────────────┤ │ │                         │ │
│         │ │ Item 3      │ │ │                         │ │
│         │ ├─────────────┤ │ │                         │ │
│         │ │ ...         │ │ │                         │ │
│         │ └─────────────┘ │ └─────────────────────────┘ │
├─────────┴─────────────────┴─────────────────────────────┤

List : Detail 비율 = 1 : 2 (또는 360px : flex-1)
```

### 스펙

```
List 패널:
  너비: 320-400px (고정) 또는 25-33% (비율)
  항목 높이: 64-80px
  항목 패딩: 12-16px
  선택 항목: 배경색 primary/10%, 좌측 3px accent bar
  구분선: 1px border 또는 gap 1px

Detail 패널:
  너비: 나머지 공간
  패딩: 24-32px
  헤더: sticky top (선택)
  빈 상태: "항목을 선택하세요" + 일러스트

리사이저 (선택):
  너비: 4px 드래그 핸들
  min/max: List 240-500px
```

### 반응형 전환

```
Desktop (1024px+): LNB + List + Detail 3열
Tablet (768-1023px): List + Detail 2열 (LNB 드로어)
Mobile (<768px): List만 표시, 선택 시 Detail로 전체 전환 (push navigation)
```

### 변형: 3단 Master-Detail

```
┌───────┬───────────┬─────────────────┬─────────────────┐
│  LNB  │ Category  │ List            │ Detail          │
└───────┴───────────┴─────────────────┴─────────────────┘

예: Slack (워크스페이스 → 채널 → 메시지 → 스레드)
예: Finder (사이드바 → 폴더 → 파일 → 미리보기)
```

## 3. Settings Layout

설정, 프로필, 환경설정 등 카테고리별 옵션을 편집하는 레이아웃.

### 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB                                                      │
├─────────┬───────────────────────────────────────────────┤
│         │ Settings                                       │
│ Settings│ ┌───────────────────────────────────────────┐ │
│ Nav     │ │ Section Title                             │ │
│         │ ├───────────────────────────────────────────┤ │
│ ● 프로필 │ │ Label                          [Control] │ │
│   알림   │ │ Helper text                              │ │
│   보안   │ ├───────────────────────────────────────────┤ │
│   연동   │ │ Label                          [Control] │ │
│   요금   │ │                                          │ │
│         │ └───────────────────────────────────────────┘ │
│         │                                               │
│         │ ┌───────────────────────────────────────────┐ │
│         │ │ Another Section                           │ │
│         │ │ ...                                       │ │
│         │ └───────────────────────────────────────────┘ │
├─────────┴───────────────────────────────────────────────┤
```

### 스펙

```
Settings Nav:
  너비: 200-240px
  항목 높이: 40px
  활성 항목: 배경색 + primary 텍스트

Content 영역:
  max-width: 720px (읽기 편한 너비)
  패딩: 32px (desktop), 16px (mobile)

설정 항목:
  레이블-컨트롤: space-between 또는 그리드 (label 40% : control 60%)
  항목 간 gap: 16-20px
  섹션 간 gap: 32-40px
  구분선: 섹션 사이 1px border (선택)

설정 그룹 (카드 스타일):
  패딩: 20-24px
  라운딩: 12px
  배경: surface 또는 card
```

### 반응형 전환

```
Desktop (1024px+): 좌측 Nav + 우측 Content
Tablet/Mobile: 상단 탭 또는 드롭다운 + 풀 Content
               또는 Settings 목록 → 선택 → 상세 (push navigation)
```

## 4. Form Page Layout

회원가입, 주문, 신청서 등 입력 중심 페이지.

### 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB (최소화 또는 생략)                                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│         ┌───────────────────────────────────┐           │
│         │ Form Title                        │           │
│         │ Subtitle / Progress               │           │
│         ├───────────────────────────────────┤           │
│         │                                   │           │
│         │ [Label]                           │           │
│         │ [Input                         ]  │           │
│         │                                   │           │
│         │ [Label]                           │           │
│         │ [Input                         ]  │           │
│         │                                   │           │
│         │ ...                               │           │
│         │                                   │           │
│         ├───────────────────────────────────┤           │
│         │              [Cancel] [Submit]    │           │
│         └───────────────────────────────────┘           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 스펙

```
폼 컨테이너:
  max-width: 480px (단일 열), 720px (2열)
  패딩: 32-40px
  배경: card 또는 surface (페이지와 구분)
  라운딩: 12-16px
  수직 중앙 정렬 (데스크톱)

필드 간격: 20-24px
섹션 간격: 32px
레이블-필드 간격: 6-8px

CTA 영역:
  상단 여백: 24-32px
  버튼 정렬: 우측 (desktop), 전체너비 스택 (mobile)
  버튼 gap: 12px
```

### 멀티스텝 폼

```
┌─────────────────────────────────────────────────────────┐
│  ① 정보 입력 ─── ② 확인 ─── ③ 완료                        │  ← 스테퍼
├─────────────────────────────────────────────────────────┤
│                                                         │
│         ┌───────────────────────────────────┐           │
│         │ Step 1: 기본 정보                  │           │
│         │ ...                               │           │
│         ├───────────────────────────────────┤           │
│         │ [← 이전]              [다음 →]    │           │
│         └───────────────────────────────────┘           │
│                                                         │
└─────────────────────────────────────────────────────────┘

스테퍼 높이: 48-56px
현재 단계: primary 색, 굵게
완료 단계: 체크 아이콘
미래 단계: muted 색
```

## 5. Content Layout

블로그, 문서, 도움말 등 읽기 중심 콘텐츠.

### 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB                                                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [TOC]          [Main Content]              [Sidebar]   │
│  200px              max 720px                 280px     │
│                                                         │
│  ● Heading 1    # Title                    Related      │
│    Heading 2    Paragraph...               ┌─────────┐  │
│    Heading 3                               │ Card 1  │  │
│  ● Heading 4    ## Subhead                 └─────────┘  │
│                 Paragraph...               ┌─────────┐  │
│                                            │ Card 2  │  │
│                 [Image]                    └─────────┘  │
│                                                         │
│                 ## Another                  Share       │
│                 Paragraph...               [🔗] [𝕏]     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 스펙

```
TOC (Table of Contents):
  너비: 200-240px
  sticky top: 80px (GNB 아래)
  max-height: calc(100vh - 160px)
  overflow-y: auto
  현재 섹션 하이라이트: primary 색

Main Content:
  max-width: 680-720px (최적 읽기 너비)
  줄 높이: 1.6-1.8
  단락 간격: 1.5em
  제목 상단 여백: 2em

Sidebar:
  너비: 240-300px
  sticky top: 80px
  콘텐츠: 관련 글, 광고, 공유 버튼 등
```

### 반응형 전환

```
Desktop (1280px+): TOC + Content + Sidebar 3열
Tablet (1024-1279px): Content + Sidebar 2열 (TOC 상단 드롭다운)
Mobile (<1024px): Content만 (TOC 햄버거, Sidebar 하단 또는 숨김)
```

## 6. Empty Page / Blank Slate

첫 사용, 데이터 없음 등 빈 상태 페이지.

### 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB                                                      │
├─────────┬───────────────────────────────────────────────┤
│         │                                               │
│   LNB   │              ┌─────────────────┐              │
│         │              │   [Illustration] │              │
│         │              │                 │              │
│         │              │   Empty Title   │              │
│         │              │   Description   │              │
│         │              │                 │              │
│         │              │   [CTA Button]  │              │
│         │              └─────────────────┘              │
│         │                                               │
├─────────┴───────────────────────────────────────────────┘
```

### 스펙

```
일러스트: 120-200px
제목: 20-24px, weight 600
설명: 14-16px, muted, max-width 400px, 중앙 정렬
CTA: primary 버튼, 설명 아래 24px 간격
전체: 수직/수평 중앙 정렬
```

## 레이아웃 공통 규칙

### 콘텐츠 최대 너비

```
읽기 콘텐츠: 680-720px (65-75자/줄)
폼: 480px (단일열), 720px (2열)
대시보드/테이블: 1440px 또는 100%
랜딩 페이지: 1200-1440px
```

### 페이지 패딩

```
Desktop: 24-32px
Tablet: 20-24px
Mobile: 16px
```

### 스크롤 동작

```
메인 콘텐츠: 세로 스크롤
사이드바/TOC: sticky 또는 독립 스크롤 (max-height 설정 시)
가로 스크롤: 테이블 내부에서만 허용
```
