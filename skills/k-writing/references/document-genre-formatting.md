# 문서 종류에 따른 형식 기준

불릿, 번호 목록, 표와 볼드는 AI 문체의 증거가 아닙니다. 독자가 글을 어떤 방식으로 읽는지에 따라 형식을 선택합니다.

## 형식 선택 원칙

- **탐색형 문서**에서는 정보를 빠르게 찾을 수 있어야 합니다. 요약, 브리핑, 체크리스트, 절차, 비교표와 상태 보고에는 목록과 강조를 사용합니다.
- **연속형 문서**에서는 논리와 맥락을 따라갈 수 있어야 합니다. 설명문, 보고서 본론, 분석과 서사에는 완결된 문단을 사용합니다.
- 한 문서 안에서도 독서 방식이 바뀌면 형식을 바꿀 수 있습니다. 보고서의 요약은 불릿으로, 본론은 문단으로 작성할 수 있습니다.
- 문장 하나를 불릿 하나로 기계적으로 분해하지 않습니다. 항목 사이에 병렬 관계가 있을 때만 목록을 사용합니다.

## 문서 종류별 기본값

| 문서 종류 | 기본 구조 | 불릿 | 볼드 |
|---|---|---|---|
| 요약 | 결론과 핵심 사실을 앞에 배치 | 적극 사용 | 핵심 결론과 라벨에 사용 |
| 브리핑 | 중요도 또는 시간순 항목 | 적극 사용 | 상태, 결정, 기한에 사용 |
| 체크리스트 | 확인 가능한 단일 행동의 목록 | 필수 | 위험하거나 필수인 행동에 제한 |
| 절차 | 순서가 있는 번호 목록 | 필수 | 단계명과 주의 사항에 사용 |
| 비교 | 같은 기준의 표 또는 병렬 목록 | 적극 사용 | 비교 기준과 우세 항목에 제한 |
| 스펙·PRD | 개요, 요구사항, 예외, 검증 기준 | 요구사항에 사용 | 필드명과 필수 조건에 사용 |
| 보고서 | 요약, 근거가 있는 본론, 결론 | 요약에 사용 | 핵심 수치와 결론에 제한 |
| 설명문 | 질문에 대한 직접 답변과 문단 | 필요한 나열에만 사용 | 탐색 지점에 제한 |
| 발표문 | 슬라이드나 발화 단위의 짧은 구조 | 화면 정보에 사용 | 한 화면의 핵심어에 제한 |

## 불릿 사용 기준

다음 조건 중 하나를 만족하면 불릿이 유용합니다.

- 세 개 이상의 항목이 같은 기준으로 병렬 관계를 이룹니다.
- 독자가 전체를 정독하지 않고 필요한 항목만 찾아야 합니다.
- 상태, 담당자, 기한 또는 선택지를 비교해야 합니다.
- 순서나 완료 여부를 확인해야 합니다.

다음 상황에서는 문단이 더 적합합니다.

- 문장 사이의 인과관계와 전제가 중요합니다.
- 각 항목이 한두 문장 이상의 설명을 계속 요구합니다.
- 목록으로 나누면 같은 주어나 결론이 반복됩니다.
- 글의 설득력이나 이해가 앞 문장의 맥락에 의존합니다.

불릿 안에서도 완성된 문장을 사용합니다. 짧은 라벨 목록처럼 문장일 필요가 없는 형식은 예외입니다.

## 볼드 사용 기준

볼드는 꾸밈이 아니라 탐색 표지입니다.

사용하기 적합한 대상은 다음과 같습니다.

- 핵심 결론 한 구절
- 상태, 담당자, 기한과 결정 사항의 라벨
- 절차의 단계명
- 독자가 놓치면 잘못 행동할 수 있는 짧은 조건

다음 방식은 피합니다.

- 문장마다 핵심으로 보이는 단어를 강조합니다.
- 한 문단의 절반 이상을 굵게 표시합니다.
- 같은 정보를 제목, 볼드와 인용문으로 중복 강조합니다.
- 강조가 없어도 동일한 위계가 드러나는 제목을 다시 강조합니다.

## 제목 작성 기준

제목은 독자가 아래 내용을 예측할 수 있도록 직접 씁니다.

- 기능, 대상, 결정, 문제 또는 질문을 구체적으로 나타냅니다.
- “먼저 알아야 할 것”, “결론부터 말하면”처럼 읽는 순서를 연출하는 표현을 기본 제목으로 사용하지 않습니다.
- 불필요한 대조, 경구, 비유와 마케팅 문구를 넣지 않습니다.
- 제목만 읽어도 내용이 있어 보이지만 실제 범위를 알 수 없는 추상어를 피합니다.

예를 들어 “조용히 무너지는 경계”보다 “플러그인 경로가 잘못 해석되는 조건”이 내용을 더 정확히 나타냅니다.
