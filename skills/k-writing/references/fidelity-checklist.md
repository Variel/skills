# 내용 보존 검증 기준

문서의 구성과 표현을 다듬은 뒤 원문, 요구사항과 최종본을 직접 대조합니다. 변경 과정의 메모나 작성자의 자체 보고만으로 판정하지 않습니다.

## 보호 항목

다음 항목은 변경 전 목록으로 기록하고 최종본에서 확인합니다.

1. 사실, 주장과 결론
2. 수치, 단위, 날짜와 시간
3. 인명, 조직명, 제품명과 기타 고유명사
4. 직접 인용과 인용의 화자
5. 링크, 파일 경로, 명령어와 식별자
6. 요구사항, 금지 사항과 승인 조건
7. 기본값, 예외와 적용 범위
8. 사용자가 수행해야 하는 행동
9. 제목, 표, 목록과 각주의 논리적 관계
10. 문서의 핵심 개념어와 분야별 기술 용어

조사, 어미, 문장 순서와 문단 구조는 바꿀 수 있습니다. 다만 변경으로 보호 항목의 의미, 강도, 조건 또는 적용 범위가 달라지면 원문을 기준으로 복원합니다.

## 내용 검사

- 원문에 있던 정보가 빠지지 않았습니다.
- 원문에 없던 주장, 수치, 인과관계와 평가가 추가되지 않았습니다.
- 가능, 권고, 의무와 금지의 강도가 바뀌지 않았습니다.
- 부정과 긍정, 주체와 객체, 전후 순서가 바뀌지 않았습니다.
- 예시가 일반 규칙이나 결론으로 확대되지 않았습니다.
- 제작 지침을 제거하면서 독자에게 필요한 제약까지 삭제하지 않았습니다.

## 구조 검사

- 제목이 본문의 실제 범위를 나타냅니다.
- 제목과 소제목이 본문 문장에 흡수되지 않았습니다.
- 목록의 병렬 기준과 번호 순서가 유지됐습니다.
- 표의 행과 열 관계가 바뀌지 않았습니다.
- 각주와 인용 출처가 원래 내용을 계속 가리킵니다.
- 요약이 본문의 결론보다 강한 주장을 만들지 않았습니다.

## 표현 검사

- 원문에 없던 마케팅 문구, 비유와 상투구가 추가되지 않았습니다.
- 전문 용어를 더 쉬워 보이는 말로 바꾸면서 정확성을 잃지 않았습니다.
- 구어체와 문어체의 격식 수준이 유지됐습니다.
- 독자에게 필요한 볼드와 목록이 남아 있으며, 장식만을 위한 강조는 제거됐습니다.
- 고친 문장이 일반적인 한국어 용법으로 읽힙니다.

## 판정

- **통과**: 보호 항목이 모두 유지되고 새 주장이나 범위 변화가 없습니다.
- **국소 수정**: 특정 문장이나 구조에서만 문제가 발견됐으며 해당 구간을 고치면 해결됩니다.
- **보류**: 원문 자체가 모순되거나 요구사항 사이의 우선순위를 판단할 근거가 없습니다. 상충하는 부분과 필요한 결정을 사용자에게 구체적으로 알립니다.

전체를 다시 쓰는 작업은 새로운 의미 변화를 만들 수 있습니다. 검증에서 발견한 문제는 영향을 받는 구간만 수정하고 다시 확인합니다.
